# AI Coding Assessment Platform

An AI-powered coding assessment and interview platform.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Monaco Editor

### Backend
- Python
- FastAPI

### AI
- OpenRouter

### Database
- SQLite for development
- PostgreSQL for production

## Features

- Interviewer dashboard
- Test creation
- Coding questions
- Candidate invitation
- Online code editor
- Code execution
- AI-powered code analysis
- Scoring
- Automated reports
